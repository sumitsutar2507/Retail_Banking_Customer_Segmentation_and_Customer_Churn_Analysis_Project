# 🏦 Retail Banking Customer Segmentation & Churn Analysis

## 📌 Project Overview
This project focuses on analyzing retail banking customer data to identify customer churn patterns, understand customer behavior, and segment customers using RFM analysis. The project was developed using **Python, SQL, and Power BI** to generate actionable business insights and improve customer retention strategies.

---

# 🚀 Project Objectives

- Analyze 10,000+ customer records
- Identify key churn drivers
- Perform Exploratory Data Analysis (EDA)
- Apply RFM-based customer segmentation
- Calculate Customer Lifetime Value (CLV)
- Build an interactive Power BI dashboard
- Generate business recommendations for customer retention

# 💰 Customer Lifetime Value (CLV)

Customer Lifetime Value was calculated using:

```python
CLV = balance × products_number
```

This helped identify:
- High-value customers
- Revenue-generating customers
- Customers requiring retention focus

# 📌 Key Business Insights

- Customers with low engagement showed higher churn probability.
- Active members had significantly lower churn rates.
- Customers with fewer products were more likely to leave the bank.
- High-value customers contributed significantly to overall revenue.
- Customer churn varied across different countries.
